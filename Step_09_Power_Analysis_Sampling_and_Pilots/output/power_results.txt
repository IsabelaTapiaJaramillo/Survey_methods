=== Assumptions ===
alpha = 0.05 | power = 0.80 | attrition = 30% | r(pre,post) = 0.50
Effect sizes (Bergquist et al., 2023): d = 0.31 (average), d = 0.18 (bias-corrected)

=== RQ1: multiple regression (pwr.f2.test) ===
u = 1 tested term, f2 = 0.02, 16 predictors in model
Required denominator df v = 392.4  ->  N = ceiling(v) + k + 1 = 410
RQ1 uses baseline (first-survey) data, so N applies at baseline.

=== H2a: attendance, invited vs not invited (pwr.2p.test) ===
p = 0.40 vs 0.25 -> Cohen's h = 0.322
n per group at follow-up = 151.2 -> 152
n per group at baseline (/ (1 - 0.30)) = 216.0 -> 216  (total 432)

=== H2b: ANCOVA (pwr.t.test with n x (1 - r^2)) ===
d = 0.31: t-test n = 164.3 -> ANCOVA n = 123.2 -> 124 per group
d = 0.18: t-test n = 485.5 -> ANCOVA n = 364.1 -> 365 per group

Sensitivity — power with 124 per group:
  d = 0.18 : power = 0.37
  d = 0.25 : power = 0.62
  d = 0.31 : power = 0.80

=== Planned sample ===
Planned baseline N = 440 (220 per arm); expected follow-up = 308 (154 per arm)
Plus ~100 new post-festival residents (testing-effect check; not powered).
Expected at follow-up: ~100 attendees vs ~208 non-attendees (unequal groups)
